## MINDMAKE X3.0 — first public beta

A second brain your AI operates, with you in control. Built to help people with ADHD, dyslexia, or too many unfinished threads return to their work.

### Start here
1. Download **MindMake-X3.0-beta.1.zip** below and unzip it.
2. Attach the single **MindMake** folder to an AI app that can read and write local folders.
3. Say **“Load up.”**

The guide is inside the folder and available separately below. You do not need the automatic “Source code” downloads to get started.

### What is included
- Saved decisions, sourced memory notes, and corrections that preserve their history.
- One task list, explicit task switching, and return points for side trips.
- Guided migration from an existing notes system, with backups, a ledger, and verified checkpoints.
- Separate Personal and Business workspaces made from a clean template.
- A report-only brain clean, daily and weekly session routines, and recorded working-style overrides.
- Permission boundaries for external or destructive actions; protected honesty and crisis rules cannot be overridden through the override tool.

### What was checked
- 368 tests across the Python suites: 366 passed, two skipped.
- The final download opens directly as one workspace; boot and the brain clean pass.
- Protected-rule refusal, interrupted override recovery, seven-day expiry, private-file rejection, and clean cloning were checked in disposable copies.

### Beta limits
- Built and checked on a Mac. Other platforms and AI applications need their own acceptance tests; Apple Reminders requires a Mac.
- The core tools need Python 3.9+; the optional personal MCP needs 3.10+. File-based assistance remains available without the Python tools.
- Prompt rules guide an AI; they do not guarantee it cannot make mistakes. Review consequential work.
- Nothing in the folder runs between chats by itself. Any reminders, remote access or background service require separate setup and verification.
- A complete real-world migration followed by a fresh-chat resume remains to be tested. That is the next beta exercise.
- Use one AI writer at a time. Keep the original system until the migration audit is complete.
